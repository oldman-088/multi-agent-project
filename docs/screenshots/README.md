# Screenshots

| Folder | Contents |
| --- | --- |
| `a11y/ar-rtl/` | Arabic UI, right-to-left — dashboard, connections, agents, runs, settings |
| `a11y/en-ltr/` | English UI, left-to-right — dashboard, connections, agents, runs, settings |
| `a11y/fa-rtl/` | Persian UI, right-to-left — connections (Connection Manager) |

Generated by the Playwright screenshot project; do not edit by hand:

```bash
npm run screenshots
```

Each image is captured only after the test asserted `<html lang>`, `<html dir>`,
the page heading and the mirrored header layout, so these files are evidence that
Arabic and Persian really render RTL and English really renders LTR. The two
Connection Manager shots (`ar-rtl/connections.png`, `en-ltr/connections.png`)
satisfy the Phase 1 requirement in `docs/SPEC.md` §5.1.

Regenerating them is part of the acceptance for any screen change — see
[`../i18n-a11y.md`](../i18n-a11y.md).
